# Service Desk ETL Pipeline

## 1. Overview
Project ETL pipeline ini dibangun untuk memroses data yang telah diambil serta dibersihkan menjadi data warehouse yang dapat dijalankan baik manual maupun otomatis menggunakan windows task scheduler dan airflow. Adapun data diambil dari hasil scrapping hasil ulasan dari aplikasi MyMRTJ. Tujuan dilakukannya project ini adalah untuk mengetahui bagaimana respon pengguna aplikasi baik respon positif, netral, maupun negatif.
